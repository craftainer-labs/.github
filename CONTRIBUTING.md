# Contributing

Thanks for your interest in craftainer-labs. These guidelines apply to
every repository in the org unless a repository states its own.

## Before you start

- Read the [Code of Conduct][coc].
- For a bug or a feature idea, open an issue first and describe the
  problem, so the approach can be agreed before you write code.
- For a security issue, do not open an issue. Follow
  [SECURITY.md][security].

## Making a change

1. Fork the repository and create a branch from `main`.
2. Read the repository's `README.md` files, from the root down to the
   directory you change. They hold its conventions.
3. Run the repository's checks before you push, typically
   `prek run --all-files --hook-stage manual`, and fix what they report.
4. Use [Conventional Commits](https://www.conventionalcommits.org/) for
   commit messages and for the pull request title.
5. Open a pull request that says what changed and why.
