# .github

Community-health and organization-profile files for the
[craftainer-labs](https://github.com/craftainer-labs) org.

- [`profile/README.md`](profile/README.md) renders as the org's homepage
  on github.com/craftainer-labs.
- [`SECURITY.md`](SECURITY.md), [`CONTRIBUTING.md`](CONTRIBUTING.md) and
  [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) are the defaults GitHub shows
  for any org repo that has none of its own.
- [`LICENSE`](LICENSE) is Apache-2.0, the license of this org's products.

Checks run with [prek](https://prek.j178.dev/) using
[`.pre-commit-config.yaml`](.pre-commit-config.yaml).
