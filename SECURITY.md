# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub private vulnerability
reporting. Open the affected repository, go to its **Security** tab and
choose **Report a vulnerability**. If you are unsure which repository is
affected, report it on
[craftainer-labs/.github](https://github.com/craftainer-labs/.github).

Please do not open a public issue, pull request or discussion for a
suspected vulnerability.

Include what you found, the affected product and version, and steps to
reproduce it.

## Supported versions

Only the latest release of each product receives security fixes. The
products are in development, and until a product has a release, only its
default branch is supported.

## What to expect

This is maintained by one person, so there is no guaranteed response
time. Reports are acknowledged and triaged on a best-effort basis, and a
fix is published as a new release with an advisory once it is ready.
Please allow time for a fix before disclosing publicly.

## Scope

This policy covers the repositories in the
[craftainer-labs](https://github.com/craftainer-labs) organization.
Vulnerabilities in the [craftainer](https://github.com/craftainer)
templates go to that organization's own repositories.
